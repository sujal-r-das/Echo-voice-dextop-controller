# Voice Assistant Commands

Here's a list of commands your voice assistant should recognize:

## Basic Actions

* "open youtube"
* "search \[query\]" (e.g., "search how to bake a cake")
* "open google"
* "shutdown"
* "volume up"
* "volume down"
* "mute"
* "unmute"
* "brightness up"
* "brightness down"
* "pause" (for media)
* "play" (for media)
* "scroll up"
* "scroll down"
* "dark mode"
* "light mode"
* "open whatsapp" (opens in Chrome)
* "open visual studio code"
* "open word"
* "take screenshot"
* "what's the time"
* "what's the date"
* "stop" or "exit"

## WhatsApp Messaging

* "send message to \[contact name/number\] saying \[message\]" (e.g., "send message to alpha saying Hello there!")
* "call \[contact name\]" (e.g., "call bravo")

## Weather

* "weather in \[city name\]" (e.g., "weather in London")

## System Information

* "battery level"
